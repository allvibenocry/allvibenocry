# Security

## Reporting a problem

Please report security problems **privately**, by email to
**hello@allvibenocry.com**, and not in a public issue. A public issue shows the
problem to everyone before it can be fixed.

Say what you found, how to reproduce it, and what you think it allows. You will
get an answer, and credit when the fix is published if you want it.

## Status

The project is in development and not ready to use, so there are no supported
releases yet. Reports are still welcome: the point is to get the foundations
right before anyone depends on them.
