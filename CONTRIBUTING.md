# Contributing

Thank you for looking.

## Issues are welcome

If something is wrong, unclear or missing, open an issue. Bug reports, questions
and ideas are all useful, even while the project is in development.

Please do **not** report security problems in an issue; see
[SECURITY.md](SECURITY.md).

## Pull requests are not accepted yet

Not because contributions are unwelcome, but because of copyright.

When you write code, you own the copyright in it. If your code were merged, the
project would have more than one copyright holder, and any future change to how
the project is licensed would need every one of them to agree. Until the
project has a contributor licence agreement, a simple document in which
contributors grant the rights needed to keep those options open, all the code
has a single copyright holder.

So for now, please open an issue describing the change instead of a pull
request. If it is a good idea, it will get built, and the issue will say who had
it.
