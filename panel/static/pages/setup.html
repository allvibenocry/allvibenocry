Set up your control panel

When it was installed, the machine showed a setup code on its own screen. Type it here, and choose the password you will sign in with. The code works once.

Four groups of four letters and digits, like ABCD-EFGH-JKLM-NPQR. Lost it? On the machine: sudo {{COMMAND}} panel setup-code
12 characters or more. A few words you will remember work well.

This panel is only on your home network, over a plain connection: someone on the same network could read what is typed here. A secure connection is planned.
